# Financial Controls

Never treat a conversational value as canonical.

Required fields for a material model: source facts, approved assumptions, model version, calculation method, scenario, sensitivity, output, confidence, and approver.

Run independent checks on material metrics before reporting them. Clearly separate customer savings, project returns, cash flow, debt-service metrics, and portfolio capital allocation.

Any change to a canonical rate, CAPEX, PPA term/rate, export value, financing condition, tax/duty assumption, or cost assumption requires approval and a versioned change record.
