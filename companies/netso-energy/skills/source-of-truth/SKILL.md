# Source of Truth

Authority order:
1. Executed legal/commercial documents.
2. Approved financial and operational records.
3. NEOS canonical database.
4. Approved company knowledge and SOPs.
5. Agent analysis.
6. Unverified inference.

For every material claim, return the source level, source identifier, effective date when known, and whether the value is fact, assumption, estimate, or inference.
