# Project Development

Lifecycle:
Opportunity → Qualification → Site Assessment → Preliminary Design → Commercial Proposal → LOI → Financing → PPA → Procurement → Installation → Commissioning → Monitoring.

A stage only advances when its entry/exit evidence is present. Never mark a stage complete solely from an agent narrative. Create blockers for missing dependencies and escalate items that threaten customer, financing, safety, or contractual commitments.
